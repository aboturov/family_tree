# Термины родства: как подписываются бейджи

Бейдж на карточке — кем человек приходится **центру дерева**. Реализация —
`web/src/tree/kinship.ts`, тесты — `web/test/kinship.test.ts`.

У неочевидных терминов есть расшифровка: подсказка при наведении на бейдж, строка в
плашке выбранного человека («муж двоюродной бабушки») и легенда «Кто есть кто» (кнопка
«?» на странице дерева) — в ней общее значение терминов, которые есть на текущем дереве.

Источники: Википедия — [Родство](https://ru.wikipedia.org/wiki/Родство),
[Свойство](https://ru.wikipedia.org/wiki/Свойство_(родство)),
[Сводные родственники](https://ru.wikipedia.org/wiki/Сводные_родственники);
[Словарь наименований родства и свойства](https://pomnirod.ru/materialy-k-statyam/knigi/genealogicheskaya-informaciya-v-gosudarstvennyh-arhivah-rossii/slovar-naimenovanij-i-ponyatij-rodstva-krovnogo-duhovnogo-i-svojstva.html);
[Схема родства (Азбука веры)](https://azbyka.ru/shemy/shema_rodstva.shtml).

## Кровное родство

Считается через ближайшего общего предка: **↑** — сколько поколений от центра вверх до
него, **↓** — сколько от него вниз до человека. Мужской / женский род.

### Прямая линия

| ↑ | ↓ | Термин |
|---|---|---|
| 1 | 0 | Отец / Мать |
| 2 | 0 | Дедушка / Бабушка |
| 3 | 0 | Прадедушка / Прабабушка |
| 4 | 0 | Прапрадедушка / Прапрабабушка |
| n ≥ 5 | 0 | Пра(n−2)дедушка — как в familio: Пра(3)дедушка |
| 0 | 1 | Сын / Дочь |
| 0 | 2 | Внук / Внучка |
| 0 | 3 | Правнук / Правнучка |
| 0 | 4 | Праправнук / Праправнучка |

### Боковые линии

«Колено» кузенов: 1 — двоюродный, 2 — троюродный, 3 — четвероюродный, 4 — пятиюродный.

| ↑ | ↓ | Термин | Кто это |
|---|---|---|---|
| 1 | 1 | Брат / Сестра | общие оба родителя |
| 1 | 1 | Единокровный брат / сестра | общий только отец |
| 1 | 1 | Единоутробный брат / сестра | общая только мать |
| 2 | 1 | Дядя / Тётя | брат или сестра родителя |
| 3 | 1 | Двоюродный дедушка / бабушка | брат или сестра деда |
| 4 | 1 | Двоюродный прадедушка / прабабушка | брат или сестра прадеда |
| 1 | 2 | Племянник / Племянница | ребёнок брата или сестры |
| 1 | 3 | Внучатый племянник / Внучатая племянница | внук брата или сестры |
| 1 | 4 | Правнучатый племянник / племянница | правнук брата или сестры |
| 2 | 2 | Двоюродный брат / сестра | ребёнок дяди или тёти |
| 3 | 3 | Троюродный брат / сестра | внук брата или сестры деда |
| 3 | 2 | Двоюродный дядя / тётя | двоюродный брат родителя |
| 4 | 2 | Троюродный дедушка / бабушка | двоюродный брат деда |
| 2 | 3 | Двоюродный племянник / племянница | ребёнок двоюродного брата |
| 2 | 4 | Внучатый двоюродный племянник / племянница | внук двоюродного брата |
| 4 | 3 | Троюродный дядя / тётя | троюродный брат родителя |

Общее правило, из которого получаются строки таблицы:

- ↑ = ↓ = k: (k−1)-юродный брат / сестра (k = 1 — родной);
- ↑ > ↓: на одно поколение старше — (↓−1)-юродный дядя / тётя; на два и больше —
  ↓-юродный дедушка / бабушка с нужным числом «пра» (↑−↓ поколений от центра);
- ↓ > ↑: на одно поколение младше — (↑−1)-юродный племянник; на два и больше —
  внучатый (правнучатый…) (↑−1)-юродный племянник.

## Свойство (родня через брак)

### Супруг центра и его родня

| Кто | Центр — мужчина | Центр — женщина |
|---|---|---|
| супруг | Жена | Муж |
| отец супруга | Тесть | Свёкор |
| мать супруга | Тёща | Свекровь |
| брат супруга | Шурин | Деверь |
| сестра супруга | Свояченица | Золовка |
| муж сестры жены | Свояк | — |
| ребёнок супруга от другого брака | Пасынок / Падчерица | Пасынок / Падчерица |

### Супруги кровных родственников

| Кто | Термин |
|---|---|
| второй супруг родителя | Отчим / Мачеха |
| второй супруг деда, прадеда… | Жена дедушки / Муж бабушки (и т.д.) |
| муж дочери, муж сестры | Зять |
| жена брата | Невестка |
| жена сына | Сноха — для отца, Невестка — для матери |
| супруг родни старшего поколения | тот же термин своего пола: муж тёти — дядя, муж двоюродной бабушки — двоюродный дедушка |
| супруг прочей родни своего и младших поколений | описательно: «Жена двоюродного брата», «Муж внучки» |
| родители супруга ребёнка | Сват / Сватья |

### Сводные

| Кто | Термин |
|---|---|
| ребёнок отчима или мачехи от другого брака (общих родителей нет) | Сводный брат / Сводная сестра |

Остальные родственники без термина в таблице подписываются «Родственник / Родственница».
